# Anomaly Correlation Alerting Service
*Category:* Data Science  
*Stack:* Node.js • TypeScript • Machine Learning  

---

## Overview
The **Anomaly Correlation Alerting Service** (ACAS) delivers real‑time alerts based on anomaly predictions generated by downstream ML models. It enriches raw anomaly scores with correlation logic, applies configurable throttling to avoid alert fatigue, and secures endpoints with JWT‑based authentication.

Key features:

- **Streaming ingestion** of prediction events (Kafka / WebSocket)
- **Correlation engine** that groups related anomalies across dimensions (e.g., time, metric, entity)
- **Dynamic throttling** (rate‑limit per entity, exponential back‑off, cool‑down windows)
- **Auth‑protected API** for alert subscription, rule management, and health checks
- **Extensible plugin system** for custom correlation strategies or notification channels (Slack, PagerDuty, email)

## Theory & Architecture
```
+-------------------+      +-------------------+      +-------------------+
|  Prediction Feed  | ---> | Correlation Layer | ---> | Throttling Layer |
+-------------------+      +-------------------+      +-------------------+
                                 |                         |
                                 v                         v
                         +-------------------+   +-------------------+
                         | Alert Dispatcher |   | Persistence Store |
                         +-------------------+   +-------------------+
                                 |
                                 v
                         +-------------------+
                         |   Notification   |
                         +-------------------+
```

### 1. Ingestion
- **Sources:** Kafka topics, HTTP webhook, or WebSocket streams.
- **Adapter pattern** abstracts source specifics into a unified `PredictionEvent` interface.

### 2. Correlation Layer
- **Windowed clustering** (tumbling or sliding windows) groups events that share:
  - Same metric family
  - Overlapping time intervals
  - Common entity identifiers (e.g., device ID, region)
- Implements **DBSCAN‑like density clustering** on a low‑dimensional feature space (`[timestamp, severity, entityHash]`).

### 3. Throttling Layer
- **Per‑entity token bucket** limits alerts to `maxRate` per minute.
- **Exponential back‑off** after each alert, resetting after a configurable cool‑down period.
- Configurable **global caps** to protect downstream notification services.

### 4. Dispatch & Persistence
- Alerts are persisted in PostgreSQL (or any SQL store) for audit.
- Dispatcher routes alerts to registered **notification plugins**.
- Plugins conform to a simple `Notifier` interface (`send(alert): Promise<void>`).

### 5. Security
- All HTTP endpoints are protected by **JWT** validated against a shared secret or OIDC provider.
- Role‑based access control (RBAC) distinguishes **admin**, **operator**, and **viewer** scopes.

## Quickstart
### Prerequisites
- Node.js ≥ 18
- Yarn or npm
- (Optional) Docker for Kafka & PostgreSQL

### 1. Clone & Install
```bash
git clone https://github.com/yourorg/anomaly-correlation-alerting-service.git
cd anomaly-correlation-alerting-service
yarn install   # or npm ci
```

### 2. Set up environment
Create a `.env` file (example):
```dotenv
# Server
PORT=8080
JWT_SECRET=super-secret-key

# Kafka
KAFKA_BROKERS=localhost:9092
KAFKA_TOPIC=anomaly.predictions

# PostgreSQL
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_DB=ac_alerts
POSTGRES_USER=ac_user
POSTGRES_PASSWORD=ac_pass
```

### 3. Run locally (Docker compose for dependencies)
```bash
docker compose up -d kafka postgres
yarn dev   # starts the TypeScript source with ts-node-dev
```

### 4. Send a test prediction
```bash
curl -X POST http://localhost:8080/api/v1/predictions \
  -H "Authorization: Bearer $(jwt encode --secret $JWT_SECRET --payload '{\"sub\":\"tester\"}')" \
  -H "Content-Type: application/json" \
  -d '{
        "metric": "cpu_utilization",
        "entityId": "host-123",
        "timestamp": 1730205600,
        "score": 0.92,
        "severity": "high"
      }'
```

### 5. Subscribe to alerts (WebSocket example)
```js
import WebSocket from 'ws';
import jwt from 'jsonwebtoken';

const token = jwt.sign({ sub: 'operator' }, process.env.JWT_SECRET);
const ws = new WebSocket(`ws://localhost:8080/alerts?token=${token}`);

ws.on('message', (data) => {
  const alert = JSON.parse(data.toString());
  console.log('🚨 Alert received:', alert);
});
```

### 6. Stop the stack
```bash
docker compose down
```
