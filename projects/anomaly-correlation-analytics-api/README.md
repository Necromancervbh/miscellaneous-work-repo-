# Anomaly Correlation Analytics API  

**Category:** Data Science  
**Stack:** TypeScript / Node.js  

Provides aggregated anomaly insights via Bayesian inference and STL (Seasonal‑Trend‑Loess) forecasts. The service abstracts the heavy statistical lifting behind a clean, type‑safe HTTP/JSON interface, making it easy to embed sophisticated anomaly detection into any JavaScript/TypeScript application.

---  

## Overview  

The Anomaly Correlation Analytics API (ACA API) ingests time‑series data, fits a seasonal‑trend model, and then applies Bayesian inference to compute the probability that observed deviations are true anomalies rather than random noise.  

Key capabilities:  

- **STL decomposition** – isolates trend, seasonal, and residual components for each series.  
- **Bayesian anomaly scoring** – updates prior beliefs with new evidence to produce calibrated anomaly probabilities.  
- **Aggregated correlation view** – combines scores across multiple series to surface systemic issues (e.g., correlated spikes across related metrics).  
- **Stateless REST endpoints** – ideal for serverless deployments or integration into existing micro‑service architectures.

## Theory / Architecture  

### 1. Data Flow  

```
Client → /ingest (raw series) → Validation → STL Decomposition
      → Residuals → Bayesian Update → /anomaly (probability scores)
      → Correlation Engine → /aggregate (system‑wide insights)
```

### 2. STL Forecasting  

- **Seasonal‑Trend‑Loess (STL)** decomposes a series `y_t` into  
  `y_t = Trend_t + Seasonal_t + Residual_t`.  
- Loess smoothing parameters (`window`, `seasonal`, `robust`) are configurable per request.  
- Forecasts are generated by extrapolating the `Trend` and `Seasonal` components, while the `Residual` distribution informs uncertainty bounds.

### 3. Bayesian Inference  

- **Prior** `P(A)` – baseline anomaly probability (default 0.01).  
- **Likelihood** `P(R | A)` – modeled using a heavy‑tailed Student‑t distribution fitted to residuals.  
- **Posterior** `P(A | R) ∝ P(R | A) * P(A)` – computed analytically for efficiency.  
- The posterior is returned as the **anomaly score** (0 – 1).

### 4. Correlation Engine  

- Constructs a covariance matrix `Σ` of residuals across all series in the current window.  
- Uses the **Mahalanobis distance** to detect multivariate outliers, producing a **systemic anomaly probability**.  

### 5. System Architecture  

| Layer                | Technology                              | Responsibility                                 |
|----------------------|------------------------------------------|------------------------------------------------|
| API Gateway          | Express.js (TypeScript)                  | Route handling, request validation            |
| Compute Service      | Node.js worker pool (worker_threads)    | STL decomposition, Bayesian updates            |
| Storage (optional)  | Redis (TTL‑based)                        | Cache recent decompositions & priors          |
| Monitoring           | Prometheus + Grafana                     | Metrics: request latency, error rates, CPU    |
| CI/CD                | GitHub Actions                           | Lint, unit tests, Docker image build, release  |

## Quickstart  

### Prerequisites  

- Node.js ≥ 18  
- Yarn or npm  
- Docker (optional, for containerised run)  

### Installation  

```bash
# Clone the repo
git clone https://github.com/yourorg/aca-api.git
cd aca-api

# Install dependencies
yarn install   # or npm ci

# Build TypeScript sources
yarn build
```

### Running locally  

```bash
# Start the server (default port 3000)
yarn start
```

The API will be reachable at `http://localhost:3000`.
