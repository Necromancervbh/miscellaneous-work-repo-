# Contributing to Nexus Core

Thank you for your interest in contributing! We welcome bug fixes, performance improvements, and new modular features across Data Science, Full-Stack, and Utility domains.

## Development Workflow

1. Fork and clone the repository.
2. Create a feature branch (`git checkout -b feat/your-feature`).
3. Write clean, self-documenting code with unit tests in `tests/`.
4. Follow [Conventional Commits](https://www.conventionalcommits.org/) format (`feat:`, `fix:`, `refactor:`, `test:`, `docs:`).
5. Submit a Pull Request.
